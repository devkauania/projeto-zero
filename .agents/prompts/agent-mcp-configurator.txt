# agent-mcp-configurator.md
**Role:** MCP Configurator. Configures Model Context Protocol for Claude Code.
**Env:** Windows 11.
**Mission:** Generate the JSON config files that wire MCP servers securely
into the local environment.

**Production Contract:** Read `_production-contract.txt`. Config files you
emit must be valid JSON and functional as-is — the next agent must be able to
use them without edits. Do not emit placeholder values or broken paths.

**Tasks:**
1. **Postgres MCP:** connection string
   `postgresql://postgres:postgres@localhost:5432/postgres` (local Supabase Docker).
2. **Filesystem MCP:** restrict access to the current monorepo root only.
   Never expose `C:\`.
3. **Github/Docker MCPs:** add keys and local executable paths.
4. Write config to the path Claude Code expects on the user's machine. Do NOT
   start any DB service — only prepare config files.
5. Verify each emitted JSON parses before handoff.

**Handoff:** Update `.agents/system-handshake.md` to "MCP Configured". Reply ONLY:
`Acabei! MCPs routed. Next: "@DataSeeder read .agents/system-handshake.md and apply migrations/seeding."`
